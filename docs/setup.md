# Підключення Supabase, AI та новин

## 1. Supabase

1. Створіть проєкт на supabase.com.
2. Застосуйте міграції з `supabase/migrations`. Через Supabase CLI: `supabase link --project-ref <ref>`, потім `supabase db push`. Інший варіант — виконати обидва SQL-файли по черзі в SQL Editor.
3. Перша міграція створює приватний бакет `attachments`. Політик для `storage.objects` навмисно немає: файли завантажує й видає лише backend.
4. **backend/.env**:
   ```
   APP_MODE=supabase
   SUPABASE_URL=https://<ref>.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=<service_role key>   # лише сервер!
   SUPABASE_JWT_SECRET=                          # для старих проєктів (HS256); інакше — JWKS автоматично
   CORS_ORIGINS=http://localhost:5173
   ```
5. **frontend/.env**:
   ```
   VITE_SUPABASE_URL=https://<ref>.supabase.co
   VITE_SUPABASE_ANON_KEY=<anon / publishable key>
   ```
6. Додайте каталог університету: `python backend/scripts/seed_supabase.py` (демо-каталог) або вручну через сторінку «Керування».
7. Призначте першого адміністратора платформи в SQL Editor: `update profiles set is_platform_admin = true where id = '<uuid>';`. Через API роль змінити не можна.

Токен користувача backend перевіряє так:
- через JWKS (`/auth/v1/.well-known/jwks.json`), якщо проєкт використовує асиметричні ключі підпису;
- через `SUPABASE_JWT_SECRET`, якщо проєкт старий і має симетричний секрет.

## 2. AI

```
AI_PROVIDER=anthropic
AI_MODEL=claude-opus-5-5
ANTHROPIC_API_KEY=<ключ>
AI_TIMEOUT_SECONDS=120
AI_RATE_LIMIT_PER_MINUTE=10
```

- Ключ зберігається лише на сервері, усі запити йдуть через FastAPI.
- Щоб замінити провайдера, реалізуйте `AIProvider` у `backend/app/integrations/ai/` і додайте його в `factory.py`.
- На випадок відмови моделі ввімкнено серверний fallback: запит автоматично повторюється на резервній моделі.
- Контекст із матеріалу додається лише після перевірки доступу до допису. Текст із вкладених файлів поки не витягується, і UI прямо про це повідомляє.

## 3. Новини університету

Джерела новин додає адміністратор університету: «Керування → Новини». Адреси беріть з офіційного сайту університету, у коді жодних адрес не прописано. Доступні три типи джерел:

| Тип | Коли використовувати | Налаштування |
|---|---|---|
| `json_api` | Університет має офіційний API | URL і мапінг полів: `{"items_path": "data", "id": "id", "title": "title", "summary": "excerpt", "url": "link", "published_at": "date"}` |
| `rss` | API немає, але є RSS або Atom | URL стрічки |
| `manual` | Немає ні API, ні RSS | Оголошення адміністратора у тій самій формі |

Як працює оновлення:
- Новини оновлюються у фоні (`NEWS_SYNC_INTERVAL_SECONDS`), а також під час запиту, якщо кеш застарів (`refresh_minutes` джерела).
- Дублікати відкидаються за парою `(source_id, external_id)` і за однаковим заголовком.
- Якщо джерело недоступне, показуються останні збережені новини з позначкою про збій.
- У налаштуваннях джерела видно час останньої синхронізації та останню помилку.

## 4. Новий університет

Адміністратор платформи створює університет (`POST /api/admin/universities`). Потім адміністратор університету заповнює через «Керування»:
- факультети, спеціальності, групи;
- предмети (один предмет можна прив'язати до кількох спеціальностей) і теми;
- джерела новин.

Код змінювати не потрібно.
