# Навантаження: ціль — 100 студентів онлайн

## Результати (листопад 2026)
Скрипт `scripts/load_test.py`: віртуальні студенти відкривають головну, предмети, новини, свої подання; раз на хвилину оновлюють сповіщення; 30 % сидять у відкритому чаті (оновлення кожні 4 с). Сервер — як на Railway: один процес uvicorn. Затримка Supabase імітується (`DEMO_DB_LATENCY_MS=60` — 60 мс на кожен запит до бази).

| Студентів онлайн | Запитів/с | p50 | p95 | p99 | Помилки |
|---|---|---|---|---|---|
| 100 | 15.7 | 370 мс | 613 мс | 617 мс | 0 % |
| 200 | 31.2 | 372 мс | 616 мс | 623 мс | 0 % |

Затримка однакова для 100 і 200 — сервер не насичується; час відповіді визначає кількість послідовних запитів до бази (головна — ~9). Критерій релізу: p95 < 800 мс і помилок < 1 % — виконано із запасом ×2.

## Що зроблено для піку
- **Завантаження файлів і новини не блокують сервер:** запити до Supabase з асинхронних обробників виконуються в пулі потоків (раніше 20 МБ подання зупиняло всіх на секунди).
- **Новини:** застаріле джерело оновлюється одним запитом, скільки б студентів не відкрили сторінку.
- **Черга генерацій:** не більше `MAX_CONCURRENT_REGENERATIONS` (за замовчуванням 4) одночасних запитів до Claude, решта чекає; захист від лімітів Anthropic і стрибка витрат.
- **Кеш сайту:** файли з хешем у назві кешуються браузером назавжди, `index.html` — завжди свіжий; gzip (найбільший файл 519 → 131 КБ). Налаштування — `frontend/public/serve.json`.

## Як перевірити самостійно
Локально (без Supabase):
```bash
cd backend
DEMO_DB_LATENCY_MS=60 APP_MODE=demo python -m uvicorn app.main:app --port 8021
python ../scripts/load_test.py --base http://127.0.0.1:8021 --demo --users 100 --seconds 60
```
На тестовому середовищі з Supabase (окремий проєкт, **не продакшн**): `--tokens tokens.txt --university <uuid>`.

## Що варто знати
- Один процес — свідомо: ліміти (AI, повідомлення, виписка Банки) живуть у пам'яті процесу. Для > 300 онлайн — перенести їх у базу й додати процеси/репліки.
- Supabase Free — 5 ГБ трафіку файлів на місяць: для 100 активних студентів з PDF-переглядом потрібен **Pro**.
